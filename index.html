Politique de Confidentialité
EAN Finder AI

Dernière mise à jour : juin 2026

En résumé : EAN Finder AI ne collecte, ne transmet et ne vend aucune donnée personnelle. Toutes les informations restent exclusivement sur votre appareil.

1. Qui sommes-nous ?

EAN Finder AI est une extension Chrome développée pour aider les vendeurs e-commerce à identifier les codes EAN/GTIN des produits et à les analyser via SellerAmp SAS.

2. Données collectées

L'extension ne collecte aucune donnée personnelle. Les seules informations stockées sont :

  • Préférences d'interface (taille du panel, mode sourcing actif/inactif) — stockées localement dans chrome.storage.local
  • Sélecteurs CSS appris par site web (pour améliorer la détection automatique) — stockés localement, jamais partagés
  • Prix temporaire détecté sur la page produit — stocké localement moins de 3 minutes, supprimé après utilisation

3. Transmission de données à des tiers

Aucune donnée n'est transmise à des serveurs externes. L'extension n'effectue aucune requête réseau vers nos serveurs.

Lorsque vous cliquez sur le bouton "SAS", votre navigateur ouvre la page sas.selleramp.com (service tiers indépendant). Vous êtes alors soumis à la politique de confidentialité de SellerAmp.

4. Accès aux sites web

L'extension analyse le contenu HTML des pages que vous visitez pour y détecter les codes EAN/GTIN. Cette analyse se fait uniquement en local, dans votre navigateur, sans aucune transmission externe.

L'extension nécessite un accès à toutes les URLs (<all_urls>) car les produits à sourcer peuvent se trouver sur n'importe quel site e-commerce.

5. Stockage local

Toutes les données sont stockées via l'API chrome.storage.local de Chrome. Ces données :

  • Restent sur votre appareil uniquement
  • Ne sont pas synchronisées avec d'autres appareils
  • Peuvent être supprimées à tout moment via les paramètres de l'extension Chrome (chrome://extensions)

6. Mineurs

Cette extension n'est pas destinée aux mineurs et ne collecte aucune information les concernant.

7. Modifications

Toute modification de cette politique sera notifiée via une mise à jour de l'extension sur le Chrome Web Store.

8. Contact

Pour toute question concernant cette politique de confidentialité, vous pouvez nous contacter via la page de support de l'extension sur le Chrome Web Store.
